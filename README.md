# vscode-dev

텔레그램 AI 비서 봇 (홈서버용). Claude + MCP filesystem 으로 옵시디언 메모, 일정 등록(네이버 캘린더 + 일간 일정표), PGM 소스 질의를 처리합니다.

## PGM 소스 질의

HTML 로 저장한 프로그램 소스를 한 폴더(하위 폴더 포함)에 모아 두면, 텔레그램으로 이렇게 물어볼 수 있습니다.

> MM1010 프로그램에서 "입고 금액" 필드는 어떻게 계산돼?

봇은 소스를 직접 찾아 읽고 아래 순서로 답합니다.

1. 프로그램 파일 특정 (파일명 일부 또는 HTML `<title>` 로 찾음)
2. 화면 라벨 `입고 금액` 검색 → 연결된 변수/컬럼명(예: `IN_AMT`) 확인
3. `IN_AMT` 를 대입·계산하는 곳(스크립트, SQL)을 따라가며 조건 분기까지 확인
4. 계산식 + 조건별 차이 + 근거 위치(`파일명:줄번호`)로 답변

### 설정

`.env` 에 폴더 경로를 넣습니다 (비우면 `G:\내 드라이브\AI\PGM소스`).

```
PGM_SOURCE_DIR=G:\내 드라이브\AI\PGM소스
# 소스 분석 정확도가 중요하면 상위 모델 권장
CLAUDE_MODEL=claude-sonnet-5-5
```

- 확장자 `.html` / `.htm` 를 읽습니다. 인코딩은 `<meta charset>` 기준이고, 표기가 없으면 UTF-8 → EUC-KR(CP949) 순으로 판별합니다.
- 태그를 제거하고 줄 번호가 붙은 텍스트로 바꿔 Claude 에 넘기므로, 원본 HTML 보다 토큰이 훨씬 적게 듭니다. 변환 결과는 파일 수정 시각 기준으로 캐시됩니다.
- 검색은 대소문자·띄어쓰기를 무시합니다 (`입고 금액` = `입고금액`).
- 긴 답변은 텔레그램 4096자 제한에 맞춰 나눠 보냅니다.

### 도구

| 도구 | 용도 |
| --- | --- |
| `list_programs` | 프로그램 목록 / 이름으로 찾기 |
| `search_program_source` | 키워드(라벨, 변수, 컬럼, 함수) 검색, 줄 번호 + 앞뒤 문맥 |
| `read_program_source` | 지정 범위 읽기 (한 번에 최대 400줄) |
